# Demo Script

1. Install dependencies: pip install -r requirements.txt
2. Train the LSTM model: python train.py --horizon 10
3. Train the XGBoost model: python train_xgboost.py --horizon 10
4. Compare results: python compare_results.py --horizon 10
5. Inspect the saved metrics and backtest files in the reports folder.
6. Run the Streamlit app: streamlit run app.py

This is an academic demo and not financial advice.
